# 🧠 NYC Schools Analysis – Database Queries  

**Tool:** Python (VS Code Notebook) + SQL  

---

## 📘 Overview  
This task focused on connecting to a **PostgreSQL database** and exploring the data both through **DBeaver** and a **Jupyter Notebook**.  

The goal was to practice querying a database, retrieving insights, and combining data from multiple tables to answer analytical questions.

---

## ⚙️ Setup  
1. Installed and configured **DBeaver** to connect to the database, view tables, and run queries.  
2. Used **Python in VS Code** to connect to the same database and execute queries directly from the notebook.

---

## 🧮 Key Questions & Analysis  

The following questions were explored during this task:  

- **Q1:** How many schools are in each borough?  
- **Q2:** What is the average percentage of English Language Learners (ELL) per borough?  
- **Q3:** Using the school demographics and high school directory data, find the top 3 schools in each borough with the highest percentage of special education students (sped_percent).  

---

## 💡 Insights  

From the analysis, I discovered several interesting trends:  

- In **Manhattan**, the **average percentage of Hispanic students** is significantly higher than other demographic groups.  
- The **average percentage of female students** is slightly higher than males across Manhattan schools.  

These insights highlight demographic patterns that could be further analyzed for diversity and inclusion purposes.
