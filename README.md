# 🗽 NYC Schools Analysis  

This **nyc-schools-analysis** project was completed as part of my **Onboarding process as an Intern at [Webeet.io](https://webeet.io)**.  

The objective was to gain hands-on experience with **real-world data stacks and workflows**, while improving my understanding of **GitHub collaboration** — including creating and working with branches, making commits, opening pull requests, and reviewing and merging code.  

Throughout the project, I also brushed up on my **Google Sheets**, **Python**, **SQL**, and **ETL (Extract, Transform, Load)** skills.

---

## 🧩 Project Structure  

The project is divided into four main sections, each focusing on a different stage of the data analysis and database workflow.  

### 1. [incident_analysis](https://github.com/BiancaNiemann/nyc-schools-analysis/tree/main/incident_analysis)  
- **File:** `school-safety-report.csv`  
- **Tool:** Google Sheets  
- **Description:**  
  Performed exploratory data analysis and answered key questions about school safety incidents using filtering, aggregation, and visualization techniques.  

---

### 2. [school_directory_exploration](https://github.com/BiancaNiemann/nyc-schools-analysis/tree/main/school_directory_exploration)  
- **File:** `high-school-directory.csv`  
- **Tool:** Python (VS Code Notebook)  
- **Description:**  
  Opened and explored the dataset in a Jupyter notebook within VS Code.  
  Cleaned and analyzed the data to uncover insights about NYC high schools and answered guided analysis questions.  

---

### 3. [database_queries](https://github.com/BiancaNiemann/nyc-schools-analysis/tree/main/database_queries)  
- **Tool:** Python (VS Code Notebook) + SQL  
- **Description:**  
  Connected to a PostgreSQL database using `psycopg2.connect` and ran SQL queries directly from the notebook.  
  Practiced querying and joining tables to extract meaningful information from the database.  

---

### 4. [database_population](https://github.com/BiancaNiemann/nyc-schools-analysis/tree/main/database_population)  
- **File:** `sat-results.csv`  
- **Tool:** Python (VS Code Notebook)  
- **Description:**  
  Designed a database schema and performed ETL steps to prepare and clean the SAT results dataset.  
  Appended the cleaned data to the PostgreSQL database for further analysis.
