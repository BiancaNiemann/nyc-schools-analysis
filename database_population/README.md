# 📝 NYC Schools Analysis – Database Population  

**File:** `sat-results.csv`  
**Tool:** Python (VS Code Notebook)  

---

## 📘 Overview  
This task focused on preparing and populating the **SAT results dataset** into a **PostgreSQL database**.  

The goal was to practice **ETL (Extract, Transform, Load) workflows**, including data cleaning, preprocessing, and appending a clean dataset to the database, while following Git workflow best practices.

---

## ⚙️ Setup  
1. Cloned the Git repository locally and opened it in **VS Code**.  
2. Connected to the branch I was working on and created a new branch for this task.  
3. Used a **Jupyter Notebook** in VS Code to inspect, clean, and prepare the dataset for database insertion.  

---

## 🧮 Data Preparation & Cleaning  

Key steps performed on the dataset included:  

- **Inspecting the dataset** to understand the structure and data types  
- **Normalizing column headers** for consistency (lowercase, replaced spaces with underscores, removed special characters)  
- **Selecting relevant columns** and discarding unnecessary ones  
- **Identifying data issues**, such as duplicates, inconsistencies, and outliers  
- **Cleaning and preprocessing** the data using Python  
- **Preparing the data** for insertion into the database  

---

## 🛠️ Database Population  

- Wrote a Python script to **connect to the PostgreSQL database**  
- **Appended the cleaned SAT results table** to the database  
- Ensured the new data integrated correctly with existing tables and maintained data integrity
