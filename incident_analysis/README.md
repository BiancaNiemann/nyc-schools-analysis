# 🏫 NYC Schools Analysis – Incident Analysis  

**File:** `school-safety-report.csv`  
**Tool:** Google Sheets  

---

## 📘 Overview  
This task focused on analyzing NYC school safety data using **Google Sheets**.  
The goal was to perform basic data cleaning, exploration, and analysis to answer a set of questions about incidents across different schools and boroughs.

---

## 🧹 Data Cleaning  
- Cleaned the **column names** by:  
  - Converting all text to lowercase  
  - Replacing spaces with underscores (`_`)  
  - Removing special characters  

This made the dataset easier to work with and ensured consistent formatting throughout the analysis.

---

## 🔍 Data Exploration & Key Questions  

| Question | Answer |
|-----------|---------|
| **How many total rows are there?** | 6,310 |
| **How many unique schools are listed?** | 1,890 |
| **What is the most frequent incident type?** | No Crime Type |
| **What % of incidents occurred in the Bronx?** | 28.24% |

---

## 💡 Additional Insights  
During further exploration, I found a few interesting patterns:  

- **Brooklyn** has the **highest number of schools and total incidents**, but not the highest count of “No Crime” incidents — that distinction belongs to the **Bronx**.  
- **Total incidents** over the years appear to be **decreasing**, while **“No Crime” incidents are increasing** over time.  

These findings may suggest improvements in reporting accuracy or changes in incident classification.

## 🧰 Tools & Functions Used  
- **Google Sheets** for cleaning, exploration, and analysis  
- **COUNTUNIQUE()** to count distinct schools  
- **Pivot Tables** to calculate averages and percentages by borough
